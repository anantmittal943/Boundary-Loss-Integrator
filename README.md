# Boundary Loss Integrator (Project 28)

Boundary-aware semantic segmentation pipeline that combines Cross-Entropy loss with an Active Contour-style Boundary Loss to produce sharper object edges.

## Project Summary

- Project Name: Boundary Loss Integrator
- Core Architecture: U-Net encoder-decoder with combined CE + Boundary loss
- Dataset Strategy: Full dataset, 10 classes
- Primary Target: Improve edge IoU for Trees (raw label 100) and Bushes (raw label 500)

## Repository Structure

- `config.py`: Centralized hyperparameters, paths, class mappings, hardware toggles
- `dataset.py`: Robust dataset and dataloader pipeline with safe loading + Albumentations
- `model.py`: U-Net model, boundary loss, combined loss, IoU helpers
- `train.py`: Training loop with logging, AMP, checkpointing, early stopping
- `test.py`: Inference timing with `time.perf_counter`, IoU metrics, confusion matrix, visuals

## Environment Setup

1. Create and activate a Python environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install albumentations pillow numpy
```

If your system does not support CUDA, install CPU-only PyTorch wheels from pytorch.org.

## Dataset Layout

Expected folder layout:

```text
data/
  dataset/
    images/
      sample_0001.png
      sample_0002.png
    masks/
      sample_0001.png
      sample_0002.png
```

Rules:
- Every image must have a mask with the same filename stem.
- Masks should use raw IDs used by the project mappings, including `100` (Trees) and `500` (Bushes).
- Unknown labels are safely mapped to ignore index (`255`).

## Class Mapping

The model is trained with 10 contiguous class IDs (`0-9`) while preserving your raw labels through remapping:

- Raw `100` (Trees) -> Train ID `8`
- Raw `500` (Bushes) -> Train ID `9`

This allows standard multi-class segmentation training while retaining edge-focused evaluation for Trees/Bushes.

## Training

Run training with defaults:

```powershell
python train.py
```

Run with custom overrides:

```powershell
python train.py --dataset-dir data/dataset --epochs 80 --batch-size 6 --learning-rate 0.0002 --device cuda
```

Training behavior:
- Uses Python `logging` (no print-based metric tracking).
- Uses mixed precision (`USE_AMP`) when available.
- Saves checkpoints to `results/checkpoints/`.
- Saves the best model by validation mean IoU (`best_model.pt`).
- Logs edge IoU for Trees and Bushes each epoch.

## Inference and Evaluation

Run inference with timing + metrics:

```powershell
python test.py --checkpoint results/checkpoints/best_model.pt --batch-size 1 --save-high-contrast 12
```

What this computes:
- Mean IoU and per-class IoU
- Edge IoU for Trees and Bushes
- Confusion matrix
- Per-image latency measured using `time.perf_counter()`

Outputs:
- Metrics JSON: `results/metrics.json` (or custom path via `--output-metrics`)
- High-contrast boundary visuals: `results/visuals/`

## Reproducibility

`train.py` sets random seeds for:
- `random`
- `numpy`
- `torch`
- `torch.cuda`

CUDNN deterministic and benchmark behavior are controlled in `config.py`.

## Performance Notes

To satisfy strict latency targets (for example, <50ms/image), consider:
- reducing `IMAGE_HEIGHT` and `IMAGE_WIDTH`
- reducing channel widths in `ENCODER_CHANNELS`
- keeping batch size at `1` for true online timing

Tradeoff:
- aggressive speed optimizations can reduce boundary fidelity, so monitor edge IoU for Trees/Bushes while tuning speed.
